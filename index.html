    Шпаргалка відкладених ордерів: який обрати і як налаштувати
    
            
    Правильний тип ордера економить комісію, захищає від просковзування та автоматизує вихід без емоцій.
    
          
    
          Золоте правило: для SL завжди Mark Price + Reduce-Only
        
    
        
    
          
    
            
    1. Buy / Sell Limit
    
            
    Коли: вхід на відкаті/ретесті або фіксація TP1/TP2.
    
            
    Як: ставиш ціну кращу за ринкову (нижче для купівлі, вище для продажу). Для ф’ючерсів на вихід вмикай Reduce-Only.
    
          
    
          
    
            
    2. Stop-Market
    
            
    Коли: жорсткий Stop-Loss при інвалідації сценарію.
    
            
    Як: задаєш ціну тригера (рівень зламу), тригер = Mark Price (захист від тіней), галочка Reduce-Only. Виконується гарантовано.
    
          
    
          
    
            
    3. Stop-Limit
    
            
    Коли: пробійний вхід або розворот (Stop-and-Reverse).
    
            
    Як: Stop = рівень пробою, Limit = на 0.15%–0.3% глибше за рухом (інакше швидка свічка проскочить повз ордер).
    
          
    
          
    
            
    4. OCO (Спот)
    
            
    Коли: одночасний Take-Profit і Stop-Loss на споті.
    
            
    Як: вводиш ціну Limit (TP) та пару Stop + Limit (SL). Щойно один спрацює — інший автоматично скасується.
    
          
    
          
    
            
    5. Trailing Stop
    
            
    Коли: супровід залишку 50% після досягнення TP1.
